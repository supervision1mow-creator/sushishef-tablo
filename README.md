# Суши-Шеф · Табло

Страница-обёртка для веб-табло «Суши-Шеф» (Google Apps Script): открывает табло на весь экран без полосы «Это приложение создано пользователем Google Apps Script».

Адрес веб-приложения задан в index.html (переменная APP). Если в Apps Script создано новое развёртывание с другим адресом, поменяйте его там.
